---

## ✨ Pixel Space

A pixel-art animation project built with HTML, CSS, and JavaScript.

The scene features:
- 🌑 A completely black night sky.
- ⭐ A dynamically generated starfield with adjustable size, density, and brightness.
- 🌀 Smooth, continuous circular rotation around a central orbital point.
- 🌌 A cinematic galaxy-like effect with subtle variations in star appearance.
- 🎨 A pixel-art aesthetic with sharp edges and a static lunar landscape.

### 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- HTML Canvas API
